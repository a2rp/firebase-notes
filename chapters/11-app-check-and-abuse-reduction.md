## What this chapter covers

Use App Check to help confirm requests come from registered apps and protect supported services.

## Topics to study

- Core concepts and the Firebase service model
- JavaScript examples using the modular SDK where appropriate
- Common mistakes, security boundaries, and practical checks
- A small hands-on exercise using a test project

## Practice

Complete the examples with a non-production Firebase project and verify each result in the Firebase console or Emulator Suite.
